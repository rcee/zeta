# Static Ant Design recommendation screen

A standalone React + Ant Design implementation. The table supports expanding rows and selecting geographies. Other controls are visual placeholders. The Figma modal title and explanatory text are retained, while the table rows match the provided screenshot. Edit the `rows` array in `src/main.jsx` to change table content.

Run `npm install`, then `npm run dev`. Run `npm run build` for a production build.
